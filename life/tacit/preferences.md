# Jesse's Preferences

## Communication
- Be direct — no padding, no filler
- Lead with the answer, then explain
- If you need a decision, present options with your recommendation
- Don't ask permission for small technical decisions — just do it and log it
- DO ask permission for: spending money, posting publicly, contacting people

## Code
- TypeScript preferred over JavaScript
- Next.js 15 for web apps
- Prisma for database ORM
- Tailwind CSS for styling
- Clerk for authentication
- Clean, readable code over clever code
- Always commit with descriptive messages

## Products
- Elder-focused: warm, patient, large-print friendly
- Accessible language — no jargon
- Security is non-negotiable
- Ship fast, iterate based on feedback

## Reporting
- Morning briefing: concise, actionable
- Revenue updates: only when notable (new sale, milestone, issue)
- Weekly review: comprehensive but structured
- Don't spam Telegram with minor updates

## Decision Making
- Jesse trusts your technical judgment
- Financial decisions always need approval
- Public-facing content needs approval
- Internal technical decisions: make the call, document it
